# MyRecipi 🍳

料理をする人のための、レシピ管理・調理支援iOSアプリです。

専門学校で学んでいるSwift / SwiftUIを使用して制作しました。
自身の調理経験を活かし、「料理中にあると便利な機能」を1つのアプリにまとめることを意識して開発しています。

## 📱 主な機能

- レシピの管理
- 食材・分量に関する便利機能
- 調理用語の確認
- フランス料理用語の確認
- キッチンツール機能
- カメラを利用した機能
- 音声入力

## 🛠 使用技術

- Swift
- SwiftUI
- Xcode

## 💡 制作の背景

製菓・調理を学び、調理業務を経験したことから、
「料理をする人が実際に使いやすいアプリ」を作りたいと考え、制作しました。

単にレシピを保存するだけではなく、
調理中に必要になる情報や機能へすぐアクセスできるアプリを目指しています。

## 🔧 工夫した点

- 調理中でも使いやすい画面構成を意識
- レシピ管理だけでなく、料理に関連する複数の機能を1つのアプリに集約
- 自身の調理経験をもとに、実際の利用場面を想定して機能を設計
